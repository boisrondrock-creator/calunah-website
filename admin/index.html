One-Time Setup — GitHub Token

Publishing saves your changes directly to GitHub so Vercel rebuilds the website automatically. You only need to do this once.

1
Go to github.com → Settings → Developer Settings → Fine-grained tokens
2
Click Generate new token. Set the name to calunah-publish, expiration to No expiration. Under Repository access → Only select repositories → choose calunah-website. Under Permissions → Repository permissions → Contents → choose Read and write. Click Generate token and copy it.
3
Go to Vercel → calunah-website → Settings → Environment Variables. Add a new variable:
Name: GITHUB_TOKEN
Value: paste your token here
Check Production, Preview, Development. Click Save.
4
Go to Vercel → Deployments, click the three dots on the latest deployment → Redeploy. Wait 30 seconds. Publishing will work automatically after this!
Enable Online Ticket Sales (Stripe)
1
In your Stripe Dashboard → Developers → API keys, copy your Secret key (sk_live_…)
2
In Vercel → Settings → Environment Variables, add:
Name: STRIPE_SECRET_KEY
Value: paste your Stripe secret key
Check Production, Preview, Development. Save, then Redeploy.
After setup, any event you add with ticket prices automatically shows a "Buy Tickets" button. Buyers pay by card / Apple Pay / Google Pay and Stripe emails them a receipt automatically. Tip: use a sk_test_… key first to test without real charges.

Video Upload (Cloudinary)

Cloudinary is a free service that hosts your videos on a fast CDN. Once configured, you can upload videos from the Videos → Upload section directly from your computer or phone.

Free setup (2 minutes):
1. Create a free account at cloudinary.com
2. In Cloudinary dashboard: Settings → Upload → Upload presets → Add preset → set to Unsigned → Save
3. Copy your Cloud Name (top of dashboard) and the preset name below
